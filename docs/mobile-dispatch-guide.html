1. Overview

ECOVENT Mobile Dispatch is a mobile app built for warehouse staff and dispatch coordinators working on phones or tablets. It focuses on the core task: loading the right duct tags onto the right vehicle and sharing the dispatch note — without the full admin portal.

Same data as the web portal
Orders, balances, and dispatch trips are shared with the admin portal. Each user signs in with their own account. All authorised users can create dispatches and update trip status.
CapabilityMobile AppAdmin Web Portal
Create dispatch tripsYesYes
Update dispatch statusYesView only
Share WhatsApp / Email / PDFYesYes
Create enquiries & design—Yes
Production tracking—Yes

Install the ECOVENT Dispatch app on each user's phone using the APK file provided by your administrator. The app connects to the ECOVENT server — no browser bookmarks required.

2. Install on Mobile (APK)

The dispatch app is distributed as an Android APK. Once installed, it appears on the home screen like any other app and opens full-screen.

Android

  1. Transfer the ECOVENT Dispatch APK file to the phone (email, WhatsApp, or USB)
  2. Open the APK file and tap Install
  3. If prompted, allow installation from unknown sources for your file manager
  4. Launch ECOVENT Dispatch from the home screen

First launch

  1. Open the app — the login screen appears
  2. Sign in with the email and password provided by your administrator
  3. You are taken directly to the Orders screen
Tip: Each dispatch operator should have their own login so actions are recorded against the correct user.

5. Create a Dispatch Trip

1
Orders — pick an order with balance > 0
2
Select Tags — use large + / − buttons per duct tag; tap All to select full available stock; sticky bar shows selected qty
3
Vehicle Details — vehicle number, driver, mobile, transporter, loading date/time
4
Confirm — review trip qty and remaining balance; tap Confirm Dispatch
5
Success — dispatch number assigned; share or view dispatch note
Rules: Cannot dispatch more than available per tag. Tags are sorted numerically (Tag 1, 2, 3… not 1, 10, 11). Order balance updates after each trip.

6. Update Dispatch Status

On the dispatch detail screen, tap status buttons to progress the trip through the loading yard workflow:

The current status is highlighted. Updates are saved immediately and visible to all users.

7. Share Dispatch Note

After creating a dispatch or from the dispatch detail screen, use the share panel:

ActionResult
WhatsAppOpens WhatsApp with a pre-filled message: dispatch no., order, vehicle, driver, item summary
EmailOpens email client with subject and body
Download PDFGenerates a printable dispatch note PDF (same format as web portal)

Ideal for sending loading instructions to the driver or confirmation to the customer site contact.

8. Mobile UI Design

The interface is optimised for gloved hands, bright warehouses, and one-handed phone use:

  • 56px touch targets on + and − quantity buttons
  • Sticky action bars — Continue and Confirm always visible at the bottom
  • Large typography — tag numbers and quantities at 2xl–3xl size
  • Safe area support — respects notches and home indicators on modern phones
  • Minimal chrome — bottom nav only on list screens; wizard steps are distraction-free
