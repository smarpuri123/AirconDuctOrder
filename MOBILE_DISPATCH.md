## 1. Overview

The ECOVENT Mobile Dispatch app is a phone-first PWA for warehouse and field staff. It connects to the same backend as the admin web portal and focuses on:

- Viewing orders ready to dispatch
- Creating multi-trip dispatches with large **+ / −** quantity controls
- Updating dispatch status (Loading → Loaded → Dispatched → Delivered)
- Sharing dispatch notes via **WhatsApp**, **email**, or **PDF**

> **Order ≠ Dispatch** — each vehicle trip is a separate dispatch record. One order can have many trips until balance reaches zero.

### Who is it for?

| Role | Primary use |
|------|-------------|
| **Dispatch coordinator** | Create trips, enter vehicle details, share notes |
| **Warehouse / loading staff** | Select tags and quantities on the shop floor |
| **Office / admin** | Monitor and update trip status from mobile |

All users with dispatch permissions can create and update dispatches.

## 2. Getting Started

### Run locally

```powershell
npm run dev:all
```

Open **http://localhost:5173/m** on your phone (same Wi‑Fi) or in Chrome DevTools mobile emulation.

### Install on phone (PWA)

| Platform | Steps |
|----------|--------|
| **Android Chrome** | Menu → *Install app* / *Add to Home screen* |
| **iPhone Safari** | Share → *Add to Home Screen* |

The app opens full-screen with ECOVENT branding.

## 3. App Structure

| Route | Screen |
|-------|--------|
| `/m/login` | Sign in |
| `/m/orders` | Orders with balance |
| `/m/orders/:id` | Order detail + new trip |
| `/m/orders/:id/dispatch` | Tag selection (+ / −) |
| `/m/orders/:id/vehicle` | Vehicle form |
| `/m/orders/:id/preview` | Confirm dispatch |
| `/m/dispatches` | All trips |
| `/m/dispatches/:id` | Detail, status, share |
| `/m/dispatches/:id/confirm` | Success + share |

Bottom navigation (**Orders** / **Dispatches**) is hidden during the dispatch wizard.

---

## 4. Create Dispatch Workflow

1. **Orders** — select an order with balance remaining  
2. **Select Tags** — tap **+** / **−** per tag (56px buttons); **All** selects full available stock  
3. **Vehicle** — vehicle no., driver, mobile, transporter, date/time  
4. **Confirm** — review qty and remaining balance  
5. **Share** — WhatsApp, email, or PDF  

**Rules:** Cannot exceed available qty per tag. Tags sort numerically (1, 2, 3…).

## 7. Mobile UI Principles

- **56px** minimum touch targets on quantity controls  
- Sticky **Continue** / **Confirm** bars at bottom  
- Large tag numbers and qty display  
- Safe-area padding for notched phones  
- Focused wizard (no bottom nav during dispatch steps)
